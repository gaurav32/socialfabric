Purpose of each file/folder in artifacts/api-server
.replit-artifact/artifact.toml — Replit's artifact manifest, used when this repo is deployed via Replit's platform. Declares it as an api service, how to run it in dev (pnpm --filter @workspace/api-server run dev) vs. production (build then node dist/index.mjs directly, skipping pnpm for faster startup), the port (8080 in Replit, vs. 3000 in the Dockerfile — different environments), and the health-check path /api/healthz. Not used by the pnpm/Docker pipeline — it's Replit-specific.

dist/ — build output, generated by build.mjs. Bundled .mjs + sourcemaps. Gitignored, safe to delete/regenerate.

node_modules/ — this package's resolved deps (pnpm workspace symlinks + hoisted packages). Gitignored, regenerated by pnpm install.

build.mjs — the actual build script (pnpm run build → node ./build.mjs). Uses esbuild to bundle src/index.ts into a single ESM file at dist/index.mjs, targeting Node. Notable details:

Externalizes a long list of native/optional packages that can't be safely bundled (native addons, CJS-only ORMs, cloud SDKs, etc.) — most aren't even dependencies today, it's a defensive allowlist for future-proofing.
Uses esbuild-plugin-pino because pino's worker-thread transport can't be bundled normally.
Injects a banner polyfilling require/__filename/__dirname since the bundle is ESM but some bundled CJS deps (like express) expect those globals.
tsconfig.json — extends the repo-wide tsconfig.base.json; scopes rootDir/outDir to src/dist; declares TS project references to lib/db and lib/api-zod (the two workspace packages it imports types from) so tsc --build can do incremental cross-package typechecking.

package.json — declares the package name, dev/build/start/typecheck scripts, and dependencies. Note dev does a full rebuild + start each time (no watch mode) — build runs esbuild, start runs node --enable-source-maps ./dist/index.mjs directly (bypassing tsx/ts-node entirely — it always runs the bundled JS, even in dev).

Dockerfile — multi-stage build for container deployment: deps (install workspace deps), build (compile via pnpm --filter @workspace/api-server build), runtime (Alpine + Node 22, copies only dist/ + reinstalls prod deps, runs pnpm --dir artifacts/api-server start on port 3000). This is the path used by cicd/server-build/.
